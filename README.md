This package is a complete replacement copy of the current GitHub Pages repository. It preserves the established visual system and adds the latest homepage, About, portfolio overview, and five flagship case studies.

## Upload

1. Unzip the package locally.
2. Open the unzipped folder.
3. Upload the contents of that folder to the root of the existing GitHub repository, replacing matching files.
4. Do not upload the outer ZIP or an extra containing folder.
