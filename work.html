I design content

Designing trust into a privacy-sensitive product experience

The audit identified trust as Autofill’s biggest adoption barrier. I redesigned language, hierarchy, disclosure, and interactions across its Save and Use experiences.

The work balanced clarity and value with legal, privacy, and security requirements—and created a reusable baseline for future experiences.

I improve workflows

Using AI to reimagine how UX content moves into code

I created a human-in-the-loop Claude Code and VS Code workflow that let content designers author and validate string changes directly in code while engineering retained review and integration ownership.

Human judgment, diff checks, and source-of-truth controls remained built into the process.
